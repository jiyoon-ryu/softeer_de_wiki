## Project

후반부에는 대규모 센서 데이터를 활용한 **Road Comfort API** 프로젝트를 진행했습니다.

도로를 주행하면서 발생하는 센서 데이터를 수집·처리하여 도로 Segment별 승차감 점수를 계산하고,
Navigation 서비스에서 후보 경로의 승차감을 비교할 수 있도록 데이터를 제공하는 프로젝트입니다.

프로젝트 기간의 설계, 구현, 장애 해결 및 성능 개선 과정 역시 `reviews`에 함께 기록했습니다.
