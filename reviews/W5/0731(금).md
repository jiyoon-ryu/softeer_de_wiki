## 1. 오늘 활동

* **한 일**: 팀 프로젝트에서 **택시기사 시간당 예상 수익 최대화 위치 추천** 아이디어를 구체화하고, TLC 데이터로 구현 가능한 범위와 추가 데이터가 필요한 부분을 정리했다.

## 2. Keep

* **문제를 실제 의사결정 상황까지 좁힌 것.** 단순 인기 지역 추천이 아니라, 승객 하차 후 다음 대기 위치를 선택하는 기사 문제로 정의했다.

  * Action: 다음에도 **누가 / 언제 / 어떤 결정을 하는지** 먼저 정리한다.
* 팀원이 힘들어할 때 위로를 해주며 함께 극복한다.

## 3. Problem

* TLC 데이터만으로는 실시간 콜 수요나 현재 기사 밀도를 직접 알 수 없는데, 초기 제안에서 이를 함께 사용할 수 있는 것처럼 표현했다.

  * 개선 Action: **실제 구현 가능한 MVP와 실시간 데이터 기반 확장안을 분리**한다.

## 4. Try

* 데이터마다 **직접 확인 가능 / 추정 필요 / 추가 데이터 필요**로 구분해 사용 여부를 결정한다.
* 추천 Zone이 실제로 더 높은 수익을 냈는지 과거 데이터로 검증하는 **Backtest**를 시도한다.
