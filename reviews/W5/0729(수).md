## 1. 오늘 활동
- **한 일:** 뉴욕시 기관 광고비 데이터와 타오바오 광고 클릭 로그를 분석해, 지역·커뮤니티별 광고 특성과 유저 특성별 광고 반응 차이를 확인함.

## 2. Keep
- 단순 데이터 조회에서 끝내지 않고 **광고 타기팅에 실제 활용할 수 있는 신호를 찾은 것.**
  - 뉴욕 광고 데이터에서는 지역·커뮤니티별 매체/광고 주제 차이를 확인
  - 유저 데이터에서는 인구통계보다 **광고 카테고리와의 조합, 과거 반응 이력**이 CTR 차이를 더 크게 만든다는 점을 확인
  - **Action:** 분석 결과가 실제 프로덕트의 어떤 입력값으로 쓰일지까지 연결해서 본다.

## 3. Problem
- 데이터의 카테고리·위치가 익명 ID라 **차이가 왜 발생했는지 구체적으로 해석하기 어려웠음.**
  - **개선 Action:** 실제 서비스에서는 의미가 명확한 Persona·광고 카테고리·Trip Context 데이터를 설계해 활용

## 4. Try
- 분석 결과를 바탕으로 **어떤 사용자에게 어떤 광고를 노출할지 판단하는 데 필요한 데이터만 선별**하고, TripMatch Ads의 Mock 데이터 설계에 반영한다.
