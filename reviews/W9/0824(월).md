## 1. 오늘 활동

Dashboard의 느린 지도 렌더링을 개선했다. Borough 전체 점수를 미리 조회하던 구조를 현재 viewport에 보이는 Segment만 조회하도록 바꾸고, 지도 전체가 아닌 필요한 영역만 다시 그리도록 수정했다. 모니터링 대시보드의 실제 Metric과 쿼리가 맞지 않는 부분도 함께 점검했다.

## 2. Keep

* **느린 원인을 단순히 서버 자원 부족으로 보지 않고 불필요한 작업 자체를 줄인 것.** 전체 데이터를 조회하고 전체 화면을 다시 그리는 대신 실제 필요한 데이터와 영역만 처리하도록 구조를 변경했다.

  * Action: 성능 문제가 생기면 자원을 늘리기 전에 실제로 필요 없는 조회·연산·렌더링이 있는지 먼저 확인한다.

## 3. Problem

* **기능은 정상 동작해도 실제 사용해 보니 불필요한 전체 조회와 재렌더링 때문에 체감 속도가 느렸다.**

  * 개선 Action: 구현 완료 여부뿐 아니라 **실제 사용 흐름에서 반복적으로 수행되는 작업까지 확인**한다.

## 4. Try

* 성능을 개선할 때 변경 전후의 **조회량, 처리 범위, 실행 시간을 숫자로 남겨 비교**해 본다.
