## 1. 오늘 활동

날씨 데이터는 Parquet에 이력을 남기면서 PostgreSQL에는 Zone별 최신 상태만 유지하도록 저장 목적을 분리했다. Sensor Producer도 Transform 2와 동일한 `road_segment`를 사용하도록 통일했고, HVFHV 데이터를 이용해 수요와 승차감 관련도를 조합한 OD 우선순위 데이터셋을 생성했다.

## 2. Keep

* **데이터의 사용 목적에 따라 저장 구조를 분리한 것.** 서빙에 필요한 최신값과 분석·추적에 필요한 이력을 같은 방식으로 저장하지 않고 각각 PostgreSQL과 Parquet으로 나눴다.

  * Action: 데이터를 저장할 때 먼저 **“최신값이 필요한가, 이력이 필요한가”를 구분한 뒤 저장 방식을 선택**한다.
* **같은 기준 데이터를 여러 컴포넌트가 공유하도록 한 것.** Sensor Producer와 Transform 2가 서로 다른 방식으로 LION을 가공하지 않고 동일한 canonical Road Segment를 사용하도록 정리했다.

## 3. Problem

* 같은 개념을 여러 컴포넌트가 독립적으로 만들면 미세한 차이가 결국 파이프라인 오류로 이어질 수 있었다.

  * Action: 여러 서비스가 공유하는 기준 데이터는 하나로 정하고 동일한 snapshot을 사용하도록 한다.
