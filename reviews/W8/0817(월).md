## 1. 오늘 활동

Transform 2가 사용하는 `road_segment`의 생성·저장 경로와 스키마를 하나로 통일하고, 좌표계를 EPSG:32118로 맞췄다. 또한 실행 환경의 타임존에 따라 `target_hour` 검증 결과가 달라지는 문제를 수정했다.

## 2. Keep

* **문제가 발생한 부분만 임시로 고치지 않고 데이터 계약 자체를 정리한 것.** Road Segment를 여러 곳에서 각각 생성하던 구조를 하나로 통일하고, 실제 Reference 생성 결과가 Transform 2까지 이어지는 통합 테스트도 추가했다.

  * Action: 파이프라인 단계가 연결되지 않을 때는 코드 하나만 보기보다 **입출력 스키마·경로·좌표계·시간 기준을 함께 확인**한다.

## 3. Problem

* **같은 데이터를 사용하면서도 각 모듈이 서로 다른 경로와 좌표계를 가정하고 있었다.** 또한 UTC 환경에서는 드러나지 않던 타임존 문제가 로컬 KST 환경에서 발생했다.

  * 개선 Action: 외부 환경에 영향을 받을 수 있는 값은 명시적으로 기준을 정하고, 서로 다른 환경에서도 테스트한다.

## 4. Try
