## 1. 오늘 활동

* **한 일:** 팀 프로젝트 **“Road Comfort API”의 AWS 실행 환경을 구성하고 서비스 간 연결 구조를 구체화했다.**
* Serving API를 위한 **EC2·ECR·RDS** 구성을 진행하고, VPC·Subnet·Security Group·IAM의 역할과 연결 방식을 확인했다.
* Spark Batch 실행을 위해 **S3와 EMR Serverless**를 구성하고, Airflow에서 EMR Serverless Job을 제출해 실행되는 것까지 확인했다.

## 2. Keep

* **AWS 서비스를 단순히 생성하는 데 그치지 않고 각 리소스가 어떻게 연결되는지 이해하면서 구성한 것.**

  * **Action:** 이후에도 리소스를 추가할 때 `누가 → 무엇에 → 어떤 권한으로 접근하는지`를 함께 확인한다.
* **로컬에서 실행하던 Spark Job을 실제 AWS 실행 환경으로 옮겨본 것.**

  * **Action:** 이후 배치 작업도 S3 입출력과 EMR 실행 결과를 기준으로 단계별 검증한다.

## 3. Problem

* IAM Role·Policy, VPC·Subnet·Security Group 등 AWS 네트워크와 권한 설정이 많아 **현재 어떤 리소스가 어떻게 연결되어 있는지 한눈에 파악하기 어려웠다.**

  * **개선 Action:** AWS 리소스와 연결 관계를 문서화하고, 실제 연결 여부는 CLI나 서비스 Health Check로 직접 검증한다.

## 4. Try

* **EC2 → RDS 연결 및 Serving API의 DB 접근을 실제로 확인한다.**
* EMR Serverless Job이 정상 완료되고 **S3 입력·출력이 정상 동작하는지 검증한다.**
* 현재 구성된 IAM·VPC·Subnet·Security Group을 정리해 전체 AWS 아키텍처를 점검한다.
