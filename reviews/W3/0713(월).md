## 1. 오늘 활동

* **한 일**: Hadoop의 등장 배경과 전체 구조를 학습하고, HDFS·YARN·MapReduce가 각각 어떤 역할을 하는지 정리했다. 특히 데이터를 여러 노드에 분산 저장하고 병렬 처리하는 흐름을 이해했다.

## 2. Keep

* **각 구성요소를 역할 중심으로 이해한 것.** HDFS는 저장, YARN은 자원 관리와 작업 배치, MapReduce는 실제 분산 처리를 담당한다는 식으로 전체 구조를 연결해서 이해했다.

  * Action: 새로운 기술을 배울 때도 **각 컴포넌트의 역할과 관계를 먼저 정리**한다.

## 3. Problem

* **NameNode, ResourceManager, ApplicationMaster, NodeManager 등 역할이 많아 처음에는 관계가 헷갈렸다.** 각각 따로 외우기보다 전체 Job 실행 흐름 안에서 이해할 필요가 있었다.

  * 개선 Action: **누가 전체 자원을 관리하고, 누가 개별 작업을 관리하고, 누가 실제 실행하는지** 기준으로 구분해 복습한다.

## 4. Try

* **Job 실행 흐름 직접 설명하기.** 클라이언트가 Job을 제출한 뒤 ResourceManager → ApplicationMaster → NodeManager → Container로 이어지는 과정을 그림 없이 설명해 본다.
