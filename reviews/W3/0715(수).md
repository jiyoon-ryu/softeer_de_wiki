## 1. 오늘 활동

* **한 일**: Hadoop Streaming과 Python으로 MapReduce 작업을 구현했다. WordCount를 시작으로 트윗 감성분석, MovieLens 평균 평점, Amazon 리뷰 집계까지 서로 다른 형태와 규모의 데이터를 HDFS에 적재하고 분산 처리했다.

## 2. Keep

* **같은 MapReduce 구조를 여러 문제에 반복 적용한 것.** Mapper에서 key-value를 만들고 Shuffle & Sort를 거쳐 Reducer에서 집계하는 흐름을 다양한 데이터셋에 적용하며 구조를 익혔다.
* **클러스터 실행 전에 로컬에서 먼저 검증한 것.** Mapper → sort → Reducer 파이프라인으로 결과를 확인한 뒤 Hadoop에서 실행해 디버깅 범위를 줄였다.

## 3. Problem

* **분산 환경에서는 코드 외에도 실행 환경과 데이터 특성을 함께 고려해야 했다.** Worker에 Python이 없으면 Map Task가 실패하고, CSV 인코딩이나 정렬 방식 같은 작은 차이도 결과에 영향을 주었다.
  * 개선 Action: 실행 전 **Worker 환경, 입력 형식, 인코딩, 정렬 기준 등을 체크리스트로 확인**한다.

## 4. Try

* Reducer 수나 데이터 크기를 변경하면서 **Shuffle과 병렬 처리 방식이 성능에 미치는 영향**을 직접 확인해 본다.
