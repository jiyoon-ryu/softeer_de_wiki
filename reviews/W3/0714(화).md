## 1. 오늘 활동

* **한 일**: Docker 환경에서 Hadoop을 직접 구성하며 HDFS의 동작을 실습했다. 단일 노드에서 시작해 NameNode/DataNode, ResourceManager/NodeManager로 구성된 멀티노드 클러스터까지 확장하고, Hadoop 설정을 수정·검증하는 스크립트도 작성했다.

## 2. Keep

* **Hadoop의 구조를 직접 구성하며 역할을 이해한 것.** 단순히 개념을 외우는 대신 단일 노드에서 멀티노드로 확장하면서 HDFS의 복제와 YARN의 자원 관리가 실제로 어떻게 동작하는지 확인했다.

## 3. Problem

* **노드와 설정 파일이 늘어나면서 설정 변경과 서비스 관리가 복잡해졌다.** 각 노드에 설정을 동일하게 적용하고 재시작한 뒤 실제 반영 여부까지 확인해야 했다.

## 4. Try

* Hadoop 설정값을 바꿨을 때 **실제 저장·처리 방식에 어떤 차이가 생기는지** 비교해 본다.
